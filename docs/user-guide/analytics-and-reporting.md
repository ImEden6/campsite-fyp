# Analytics and Reporting User Guide

## Overview

The Analytics and Reporting module provides comprehensive business intelligence tools to help you understand your campsite's performance, track revenue, monitor occupancy, and gain insights into customer behavior.

**Available to**: Admin, Manager roles

---

## Dashboard Metrics

### Accessing the Dashboard

1. Log in with an Admin or Manager account
2. Navigate to **Dashboard** from the main menu
3. The dashboard displays key performance indicators (KPIs) at a glance

### Key Metrics

The dashboard shows four primary metrics with period-over-period comparisons:

#### Total Revenue
- Displays total revenue for the selected period
- Shows percentage change from the previous period
- Green indicator for growth, red for decline

#### Occupancy Rate
- Shows the percentage of occupied sites
- Compares to the previous period
- Helps identify booking trends

#### Active Bookings
- Number of current and upcoming bookings
- Tracks booking volume changes
- Useful for capacity planning

#### Total Customers
- Total number of customers in your system
- Shows customer growth rate
- Indicates business expansion

### Customizing Date Ranges

1. Click the **Date Range** selector at the top of the dashboard
2. Choose from preset ranges:
   - Today
   - Last 7 days
   - Last 30 days
   - Last 90 days
   - This year
   - Custom range
3. For custom ranges, select start and end dates
4. Click **Apply** to update all metrics

## Revenue Analysis

### Revenue Overview

The Revenue section provides detailed financial analysis:

1. Navigate to **Analytics** > **Revenue**
2. View total revenue for the selected period
3. See revenue growth percentage
4. Analyze revenue by site type

### Revenue by Site Type

Understand which site types generate the most revenue:

- **Tent Sites**: Revenue from tent camping
- **RV Sites**: Revenue from RV hookups
- **Cabins**: Revenue from cabin rentals
- **Equipment Rentals**: Additional revenue from equipment

Each category shows:
- Total revenue amount
- Percentage of total revenue
- Number of bookings

### Revenue Trends

The revenue chart displays time series data:

1. Select grouping: **Day**, **Week**, or **Month**
2. View revenue trends over time
3. Identify seasonal patterns
4. Compare different time periods

**Tips:**
- Use daily grouping for short-term analysis (1-2 weeks)
- Use weekly grouping for monthly analysis
- Use monthly grouping for yearly trends

### Filtering by Site Type

To analyze revenue for specific site types:

1. Click the **Site Type** filter
2. Select one or more site types
3. The chart and metrics update automatically
4. Clear filters to see all site types

Monitor how efficiently your sites are being utilized:

1. Navigate to **Analytics** > **Occupancy**

## Site Performance

### Performance Metrics

Analyze individual site performance:

1. Navigate to **Analytics** > **Sites**
2. View performance table for all sites
3. Sort by any metric
4. Identify top and underperforming sites

### Metrics per Site

Each site displays:

- **Revenue**: Total revenue generated
- **Bookings**: Number of bookings
- **Occupancy Rate**: Percentage of time occupied
- **Average Rating**: Customer satisfaction score
- **Average Stay**: Typical booking duration

### Using Performance Data

**Identify Top Performers:**
- Sort by revenue or occupancy
- Understand what makes them successful
- Apply learnings to other sites

**Improve Underperformers:**
- Identify sites with low occupancy
- Review pricing strategy
- Consider improvements or amenities
- Adjust marketing focus

**Optimize Pricing:**
- Compare similar sites
- Adjust prices based on demand
- Maximize revenue potential

## Report Generation

### Available Reports

The system offers several pre-built reports:

#### Financial Reports
- Revenue Summary
- Payment History
- Refund Report
- Tax Report

#### Operational Reports
- Booking Summary
- Occupancy Report
- Check-in/Check-out Log
- Site Utilization

#### Customer Reports
- Customer List
- Booking History
- Customer Demographics
- Retention Analysis

#### Inventory Reports
- Equipment Rental Report
- Equipment Availability
- Maintenance Log

### Generating a Report

1. Navigate to **Analytics** > **Reports**
2. Click **Generate New Report**
3. Select report type from dropdown
4. Configure report parameters:
   - Date range
   - Site types (if applicable)
   - Grouping options
   - Filters
5. Choose output format:
   - **CSV**: For spreadsheet analysis
   - **PDF**: For printing or sharing
   - **Excel**: For advanced analysis
6. Click **Generate Report**
7. Wait for generation (usually 10-30 seconds)
8. Download the report file

### Report Parameters

Different reports require different parameters:

**Date Range:**
- Start date
- End date
- Preset ranges available

**Filters:**
- Site type
- Booking status
- Customer type
- Payment method

**Grouping:**
- Daily
- Weekly
- Monthly
- Quarterly

### Report History

Access previously generated reports:

1. Navigate to **Analytics** > **Reports** > **History**
2. View list of generated reports
3. See generation date and parameters
4. Download reports (available for 30 days)
5. Regenerate expired reports

**Note:** Reports expire after 30 days for security and storage reasons.

## Real-Time Updates

### Live Dashboard

The dashboard updates automatically with real-time data:

- New bookings appear immediately
- Revenue updates in real-time
- Occupancy changes reflect instantly
- No need to refresh the page

### Update Indicators

Visual indicators show when data updates:

- Subtle animation on metric cards
- "Updated just now" timestamp
- Automatic chart refreshes

### Manual Refresh

To manually refresh data:

1. Click the **Refresh** button in the top right
2. Or use keyboard shortcut: `Ctrl+R` (Windows) or `Cmd+R` (Mac)

## Exporting Data

### Export Options

Export analytics data for external analysis:

1. Navigate to any analytics view
2. Click the **Export** button
3. Choose format:
   - CSV for spreadsheets
   - JSON for data processing
   - PDF for presentations
4. Data downloads immediately

### What Gets Exported

- Current view's data
- Applied filters
- Selected date range
- All visible metrics

## Troubleshooting

### Data Not Loading

If analytics data doesn't load:

1. Check your internet connection
2. Refresh the page
3. Clear browser cache
4. Try a different browser
5. Contact support if issue persists

### Incorrect Metrics

If metrics seem incorrect:

1. Verify date range selection
2. Check applied filters
3. Ensure you have latest data (refresh)
4. Compare with raw booking data
5. Report discrepancies to support

### Report Generation Fails

If report generation fails:

1. Check date range isn't too large
2. Reduce number of filters
3. Try a different format
4. Wait a few minutes and retry
5. Contact support with error details

### Slow Performance

If analytics load slowly:

1. Reduce date range
2. Apply more specific filters
3. Close other browser tabs
4. Check internet speed
5. Try during off-peak hours

## Tips and Tricks

### Keyboard Shortcuts

- `Ctrl/Cmd + R`: Refresh data
- `Ctrl/Cmd + E`: Export current view
- `Ctrl/Cmd + P`: Print current view
- `Ctrl/Cmd + F`: Search/filter

### Quick Comparisons

- Hold `Shift` and click date ranges to compare periods
- Use the comparison toggle for side-by-side views
- Export both periods for detailed analysis

### Custom Views

- Save frequently used filter combinations
- Create custom date range presets
- Bookmark specific analytics pages

### Mobile Access

- Access analytics on mobile devices
- Swipe to navigate between metrics
- Tap and hold for detailed tooltips
- Use landscape mode for charts
