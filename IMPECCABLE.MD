# Sanctuary Design Context

## Design Context

### Users

- **Seekers of Serenity**: Individuals looking for an escape into nature, prioritizing peace, quietude, and a "trace-less" experience.
- **Purpose**: To provide a seamless, premium booking experience that feels as immersive as the campsites themselves.

### Brand Personality

- **Serene**: Calm, minimalist, and spacious.
- **Premium**: High-end editorial feel, attention to micro-interactions, and hand-crafted aesthetics.
- **Articulate**: Precise typography, thoughtful spacing, and clear visual hierarchy.

### Aesthetic Direction

- **Nature-Inspired OKLCH**: Using organic color scales (Moss, Stone, Bark, Ember) for a cohesive, earthy feel.
- **Cinematic Depth**: Implementing radial mist gradients and high-quality photography with atmospheric overlays.
- **Analog Texture**: A global grain overlay (SVG noise) to eliminate digital flatness and add a "tangible" feel.
- **Glassmorphism**: Using `.nature-glass` (backdrop-blur and subtle borders) for UI elements that feel integrated into the environment.

### Design Principles

1. **Prioritize Atmosphere**: The interface should feel "alive" through subtle animations and mist effects.
2. **Editorial Hierarchy**: Use bold, asymmetric layouts and premium serif typography (Lora) for headings.
3. **Organic Interactions**: Hover states and transitions should be soft and deliberate (duration-700+).
4. **No Digital Flatness**: Always apply grain-overlay and avoid generic grays or solid primary colors.
5. **Sanctuary Orange**: Use `secondary-500` (Ember/Soil) for critical interactive accents like search icons and price ranges.
